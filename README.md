# Yürüyen Merdiven Sol Şerit Mahkemesi

Bu depo bir şakadır. Ama çalışır. İkisi aynı anda olabilir, merdiven de aynı anda hem çıkar hem iner.

## Misyon (abartılı, kasıtlı)

Sağ şerit bir öneri değildir. Sağ şerit bir medeniyet sınırıdır. Sol şeritte duran vatandaş, arkadan gelen insanlığın zamanını rehin almış sayılır. Bu yazılım, o rehine krizini tutanakla çözer.

Ceza birimi Türk lirası değildir. Ceza birimi **adım**dır. Nakit, havale ve "ben zaten iniyordum" kabul edilmez.

## Suç cetveli

| Suç | Adım katsayısı |
| --- | --- |
| durmak | 40 |
| telefona-bakmak | 25 |
| bavul | 55 |
| konusmak | 15 |
| ters-yurumek | 80 |
| merdiveni-selamlamak | -10 (berat ve madalya) |

Toplam ceza = katsayı × kat. 7. katta bavul taşımak, hukuk tarihinde ağır basar.

## Kurulum

Python 3 yeter. Bağımlılık yok. Merdiven de yok, o sizin sorununuz.

```bash
python merdiven_mahkemesi.py "Şemsiyeli Adam" durmak --kat 4
python merdiven_mahkemesi.py "Bavulcu" bavul --kat 7
python merdiven_mahkemesi.py "Nazik Yolcu" merdiveni-selamlamak --kat 2
```

Aynı sanık ve aynı suç her seferinde aynı tutanak numarasını üretir. Hukuk böyle istikrar ister. Hayat istemez, o ayrı.

## Neden bu kadar ciddi?

Çünkü ciddi olmayan şeyler de protokol ister. Kapı zili diplomasisi başka dosyadır. Çaydanlık sendikası başka dosyadır. Bu dosya sadece basamakların taraf tutmasını belgeler.

## Bilinen kusurlar

- Merdiven gerçekten durursa mahkeme de durur. Bu bir özelliktir.
- Hakimler sanaldir. İtiraz merdivenin altına bırakılır, orada kaybolur.
- Sol şerit savunması ("yer yoktu") otomatik reddedilir. Yer yoktur, o yüzden sağdan geçilir.
